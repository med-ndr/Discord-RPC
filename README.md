# Discord RPC for Arch Linux

A Python script using `pypresence` to show your Arch Linux status and running kernel version on Discord Rich Presence.

## Requirements
- Arch Linux
- Discord desktop app running
- Python 3 and `pypresence`: `pip install pypresence --break-system-packages`

## Discord Developer Setup
- Open Discord Developer Portal and create a New Application
- Copy the Application ID and paste it in `arch_rpc.py`
- Add an Arch Linux photo under Rich Presence / Art Assets

## Run
`python3 arch_rpc.py`
